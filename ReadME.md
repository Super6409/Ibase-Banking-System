# Ibase Banking System



This is a simple banking system made using Python for the India AI Ibase mini project-1.



### Features



* Create Account
* Deposit Money
* Withdraw Money
* Check Balance
* Exit
* Excel file storage



### Technologies Used



* Python
* OpenPyXL
* Microsoft Excel



### How to Run



1. Install openpyxl:

2. pip install openpyxl

3. Then run:

4. python "Ibase Project-1.py"
